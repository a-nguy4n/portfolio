Overview

Weather Wardrobe is an IoT-powered wardrobe assistant that combines real-time temperature readings, weather forecasts, and AI to help users make everyday outfit decisions.

Built as a full-stack class project, the application connects physical sensors to a personalized web dashboard. Users can register ESP32 devices, view live temperature data, and ask an AI assistant for weather-informed clothing recommendations.

THE OBJECTIVE

Connecting physical sensors to everyday decisions.

The goal was to collect environmental data from hardware, transmit it to a web application, and turn it into useful information through an interactive interface.
